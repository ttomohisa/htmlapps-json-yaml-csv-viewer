# LLM workflow

1. Read `AGENTS.md` and `APP_SPEC.md`.
2. Inspect `src/index.template.html`.
3. Preserve local-first, single-HTML, no-runtime-network constraints.
4. Update source/config/docs together.
5. Run `scripts/check-repository.ps1` on Windows.
6. Review both generated HTML variants and manifests.
